# DevOps Portfolio

This repository brings together a set of practical DevOps and cloud engineering projects designed for portfolio use and technical review.

## Included projects

1. Jenkins CI/CD with Docker and Kubernetes
2. AWS infrastructure automation using Terraform
3. Ansible configuration management and automation
4. DevSecOps pipeline with SonarQube and Trivy
5. Kubernetes monitoring with Prometheus and Grafana
6. GitOps platform project on AWS

## Purpose

This portfolio is intended to demonstrate hands-on skill in:

- CI/CD pipeline design
- containerization with Docker
- Kubernetes deployment patterns
- infrastructure provisioning with Terraform
- configuration automation with Ansible
- security scanning with SonarQube and Trivy
- observability with Prometheus and Grafana
- GitOps and platform automation concepts

## Quick start

Each project contains its own README with setup and execution steps. Follow the instructions inside the relevant project folder.

## Notes

- This is a local-first portfolio repository.
- Secrets and credentials are not committed.
- Projects are intended for learning, demonstration, and recruiter-facing technical review.
- Production deployments and cloud billing are not claimed unless explicitly verified.
