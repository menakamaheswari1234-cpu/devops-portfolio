# DevOps Portfolio

This repository contains five practical DevOps projects for portfolio use.

## Projects

1. Jenkins CI/CD with Docker and Kubernetes
2. AWS Terraform Infrastructure Automation
3. Ansible Configuration Management
4. DevSecOps with SonarQube and Trivy
5. Kubernetes Monitoring with Prometheus and Grafana
